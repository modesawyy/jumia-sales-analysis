# Jumia Sales Analysis Dashboard

This project is an end-to-end e-commerce sales analysis dashboard built using SQL and Power BI to analyze sales, customer behavior, and product performance.

## Project Features

* Sales Performance Analysis
* Customer Insights Dashboard
* Product & Category Performance
* Executive Summary Dashboard
* Interactive Filters and Navigation
* Row-Level Security (RLS)

## Tools Used

* SQL
* Power BI

## Key KPIs

* Total Sales
* Total Orders
* Total Profit
* Profit Margin
* Customer Growth
* Average Order Value (AOV)

## Dashboard Highlights

* Interactive dashboards with slicers and drill-down analysis
* Customer segmentation and churn insights
* Product and category profitability analysis
* Monthly sales trend tracking
* Secure category-based access using Row-Level Security (RLS)

## SQL Analysis Included

* Customer sales ranking
* Product category performance analysis
* Sales trend analysis
* Delivery time analysis
* Top-performing products and customers
* Stored Procedures and Views
* Window Functions and CTEs
